# 🍰 Cake Baker Portfolio

> A stunning, full-stack MERN portfolio website for showcasing cake artistry — immersive 3D visuals, modern UI, and seamless admin control.  
> 🌐 **Live Demo:** https://nutty-bakers.pages.dev/

---

## 🚀 Highlights

- 🎨 **3D Hero Section** — React Three Fiber animations  
- 🌓 **Dark / Light Mode** — Theme toggle  
- 💬 **Testimonials & Contact** — Integrated feedback & email alerts  
- 🔐 **Secure Admin Dashboard** — JWT Auth  
- ⚡ **Fast & SEO-Ready** — Vite + React Helmet  
- 📱 **Fully Responsive** — Mobile & desktop ready  

---

## 🛠 Tech Stack

**Frontend:** React (Vite), Tailwind CSS, Framer Motion, React Three Fiber  
**Backend:** Node.js, Express, MongoDB, JWT, Multer, Nodemailer  

---

## ⚙️ Quick Start

```bash
# Clone repository
git clone https://github.com/yourusername/cake-baker-portfolio.git

# Backend
cd cake-baker-portfolio/backend
npm install
npm run dev

# Frontend
cd ../frontend
npm install
npm run dev
